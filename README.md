# Hito 7 Landing Page

Esta es una página sencilla que presenta de forma básica la marca **Hito 7**. El proyecto incluye un manual de marca en PDF que describe la identidad visual y lineamientos de uso. Puedes abrir `index.html` en tu navegador o usar la carpeta `docs/` para publicar la página mediante GitHub Pages.

## Uso

1. Clona este repositorio y abre `index.html` para ver la página localmente.
2. Si utilizas GitHub Pages, el contenido de la carpeta `docs/` será el que se publique.
3. Revisa el archivo [`ManualDeMarca-Hito7.pdf`](ManualDeMarca-Hito7.pdf) para conocer todo el detalle de la identidad visual.

## Estructura

- `index.html` – Página principal.
- `docs/index.html` – Versión para GitHub Pages.
- `css/styles.css` – Estilos generales.
- `js/script.js` – Código JavaScript mínimo.
- `images/` – Imágenes de apoyo.

## Créditos

El manual de marca y los recursos gráficos pertenecen a **Hito 7**.
