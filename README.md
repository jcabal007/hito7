# Hito 7 Landing Page

Esta página web presenta de manera resumida la identidad de marca **Hito 7**. Se basa en el Manual de Marca incluido en el repositorio y resume misión, oferta de servicios, modelo de trabajo e impacto.

## Uso
1. Clona este repositorio y abre `index.html` para ver la página localmente.
2. Si utilizas GitHub Pages, publica la carpeta `docs/`.
3. El archivo [`ManualDeMarca-Hito7.pdf`](ManualDeMarca-Hito7.pdf) contiene la guía completa.

## Estructura
- `index.html` – Página principal.
- `docs/index.html` – Versión para GitHub Pages.
- `css/styles.css` – Estilos.
- `js/script.js` – Código JavaScript mínimo.
- `images/` y `docs/*.jpg` – Recursos gráficos.

El sitio incluye navegación interna, misión, qué hacemos, cómo lo hacemos, impacto, valores, testimonios y un formulario de contacto. Consulta el manual si necesitas aplicar la marca en otras piezas.

## Créditos
El manual de marca y los recursos gráficos pertenecen a **Hito 7**.
